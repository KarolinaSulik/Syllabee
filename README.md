# Syllabee

Prosta webowa gra do nauki czytania metodą sylabową dla małych dzieci.

## Uruchomienie

Nie trzeba nic instalować. Otwórz plik `index.html` w nowoczesnej przeglądarce, np. Chrome, Safari lub Firefox.

1. Wybierz jeden z trzech poziomów.
2. W Level 1 wpisuj pojedyncze litery z fizycznej klawiatury.
3. W Level 2 wpisuj całe słowa, litera po literze.
4. W Level 3 klikaj sylaby w odpowiedniej kolejności.

Po poprawnej literze lub sylabie gra odtwarza krótki pozytywny ton. Błędna odpowiedź nie pojawia się na ekranie i ma spokojny niski ton. Dźwięki są tworzone w przeglądarce — bez dodatkowych plików audio.

## Dodawanie słów

Wszystkie zadania są w tablicy `words` na początku pliku `script.js`. Każdy wpis zawiera słowo, podział na sylaby, emoji, poziomy i sylaby do wyboru. Emoji można później zastąpić obrazkami z `assets/images`.
